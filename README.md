# Financial Collusion Ring Detection

Toporing studies transaction-preserving graph, cellular and simplicial representations for exact cycle membership recovery. Earlier IBM AMLworld/Elliptic investigations remain separate exploratory context. The current manuscript describes a controlled AMLSim benchmark of exact persisted generated CYCLE membership.

The retained fixed-summary GBDT mean AP was 0.8561 on the registered simulator worlds, compared with 0.7497 for a summary neural control and 0.2149–0.2793 across the graph/complex arms. The complete paper preserves the summary-neural advantage on one world and all negative findings. Neural learning qualification and population precision remain unresolved; no topology mechanism or financial efficacy is established.
